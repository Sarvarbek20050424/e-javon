# E-javon jamoa loyihasi — hisobot

Hisobotning chop etishga tayyor, A4 formatlangan nusxasi: [hisobot.html](hisobot.html). Brauzerda ochib **Print / Chop etish → Save as PDF / PDF sifatida saqlash** tanlang.

Ushbu hisobot E-javon foydalanuvchilari uchun qo‘llanmalar kontent-loyihasini, loyiha maqsadini, Kanban ish oqimini, vazifalar ro‘yxatini va ism-familiyasiz rol taqsimotini bayon qiladi. Rejalashtirilgan mehnat hajmi 32 soat; haqiqiy bajarilish va hissa ulushlari ish tugagach hisoblanishi kerak. Hujjat bajarilmagan vazifalarni bajarildi deb ko‘rsatmaydi.
